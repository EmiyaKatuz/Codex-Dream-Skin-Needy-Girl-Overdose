# 自定义背景制作指南

[中文](./reference-background-prompt-guide.md) · [English](./reference-background-prompt-guide.en.md)

制作适合 Codex 界面的背景图，再通过 DreamSkin Studio 导出主题 ZIP。

## 把生成图片做成可导入主题

1. 生成 `2560 × 1440`、16:9 的背景图，保留左侧内容区和右侧主体。
2. 在 [DreamSkin Studio](https://dreamskin.cc/studio) 导入 JPEG、PNG 或静态 WebP，文件最大 **10 MiB**。调整配色，并预览明暗模式、首页、任务页和不同窗口宽度。
3. 填写主题名称、作者、平台与素材来源，导出包含 `manifest.json`、`theme.json`、非空 `theme.css` 和唯一背景图的 ZIP。`theme.css` 须通过 Safe CSS 校验。
4. macOS 菜单栏选择「主题 → 导入主题 ZIP…」；Windows 托盘选择「导入主题 ZIP…」。导入后，从「已保存的主题」选择应用。

背景透明度由主题颜色和客户端设置控制。把文字、控件及界面蒙层留给运行时绘制，背景图片保持完整、不透明的画面。

## 画布与构图

在生成器的尺寸设置中选择 `2560 × 1440`。若不支持该尺寸，先生成 16:9 横图，再等比缩放或裁切。

| 区域 | 建议范围 | 构图 |
| --- | --- | --- |
| 原生内容区 | `x=0%–52%` | 低细节、低对比，保留柔和纹理 |
| 过渡区 | `x=45%–62%` | 连续的环境、光线和透视 |
| 关键主体 | `x=62%–88%`、`y=16%–72%` | 脸、手及主要道具集中于此 |
| 人物位置 | 脸 `y=20%–52%`；手 `y=30%–70%` | 兼顾窗口裁切及底部输入区 |
| 边缘 | 关键内容距边至少 `8%` | 四周使用可延展的环境 |

背景按 `cover` 铺满窗口，不同比例会裁切边缘。浅色与深色界面下都应保留中间调和主体层次。

右侧主体可参考以下 `theme.json` 配置：

```json
{
  "appearance": "auto",
  "art": {
    "focusX": 0.72,
    "focusY": 0.45,
    "safeArea": "left",
    "taskMode": "ambient"
  }
}
```

`safeArea: "left"` 为原生内容预留左侧空间，窄窗口优先保护右侧主体。

## 场景模板

替换方括号中的内容，描述具体场景、材质、光线和颜色。

```text
制作一张 2560×1440、16:9、不透明的桌面背景。
场景：[环境、季节和主要物件]。媒介：[摄影、水彩或数字插画]。
材质：[3–5 种可见材质]。光线：[方向、软硬和时段]。
色板：[4–6 种颜色]。

左侧 x=0%–52% 保留连续、低细节、低对比的环境纹理。
主视觉集中在 x=62%–88%、y=16%–72%，关键内容距边至少 8%。
全画面使用统一透视和自然过渡，明暗界面叠加后仍有中间调细节。
仅输出背景画面，不含界面控件、文字、标志或水印。
```

## 人物模板

```text
制作一张 2560×1440、16:9、不透明的桌面背景。
一位原创成年角色位于右侧，外观为[发型、服装、姿态和表情]。
场景：[环境与道具]。材质：[布料、植物、玻璃等]。
风格：[摄影或插画媒介]。光线：[主光与环境光]。色板：[颜色]。

左侧 x=0%–52% 延续同一环境，细节和对比保持柔和。
完整脸部、手部和主要道具位于 x=62%–88%、y=16%–72%；
脸部 y=20%–52%，手部 y=30%–70%，关键内容距边至少 8%。
保持自然的人体比例、统一光线和连续背景。
仅输出背景画面，不含界面控件、文字、标志或水印。
```

## 使用参考图

按实际上传顺序，在提示词中写清每张图的用途：

| 参考 | 用途 |
| --- | --- |
| 界面截图 | 提取色板、光线、氛围和大致构图，重建完整背景场景 |
| 场景或材质图 | 提取环境、表面质感、景深和光影 |
| 有使用授权的人物图 | 保持主体外观和自然比例 |

例如，上传一张界面图和一张人物图时，可追加：

```text
Image 1 提供色板、光线和构图参考，生成新的连续背景场景。
Image 2 提供人物外观参考，将主体自然放入右侧安全区。
```

## 透明度与本机管理

背景透明度优先使用本机按主题保存的设置，其次是作者设置的颜色 alpha，未指定时默认 **30% 透明**。例如，`rgba(17, 19, 24, 0.7)` 为 70% 不透明，即 30% 透明。

macOS 从「主题」菜单调节；Windows 打开原生管理窗口。滑块范围为 0–100%，「跟随主题」恢复作者设置。删除主题前先切换到其他主题，确认后移入废纸篓或回收站。

详细操作见[本机主题管理](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/main/docs/theme-management.md)。

## 导出前检查

- 图片尺寸、比例与文件大小符合要求。
- 以 16:9、16:10、4:3 和超宽窗口预览 `cover` 裁切，主体完整。
- 明暗界面下文字清晰，背景过渡自然。
- 图片只包含背景艺术；主题 ZIP 包含完整元数据、CSS 与背景。

更多配色与场景示例见[背景创作提示词](./background-generation-prompts.md)。
