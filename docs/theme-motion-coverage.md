# 动效计划落实情况

[中文](./theme-motion-coverage.md) · [English](./theme-motion-coverage.en.md)

本页对应[原始动效计划](./theme-animation-roadmap-2026-10-03.md)的 01–17 项客户端效果。设置入口见[动效设置](./theme-motion.md)。原计划中的“已有／缺口”是历史分析；当前实现以下表为准。

## 效果清单

| 编号 | 已实现效果 | 触发与边界 |
| --- | --- | --- |
| 01 | 输入框聚焦边缘与退出过渡 | 仅绘制内侧边缘，保持光标、输入法和原生尺寸 |
| 02 | 按钮按压、静态图标 1px 回弹 | 鼠标及 Enter／空格；支持已识别侧栏、设置与环境操作，跳过重复按键、输入法、禁用控件及原生动画 |
| 03 | 侧栏、终端 Tab 与设置选中边缘 | 根据明确的选中属性绘制，不移动行或滚动区域 |
| 04 | 菜单、命令面板短亮边 | 新挂载和预挂载菜单均按打开边界反馈；关闭立即清理，保留原生定位和动画 |
| 05 | 首页建议／主题卡与项目卡错峰亮边 | 首批最多四项、间隔 25ms；自有卡与项目按稳定 ID 去重，无身份的原生建议只反馈首批，避免虚拟化重播 |
| 06 | 新权限提示注意反馈 | 原生请求驱动待确认状态；明确打开的模态权限提示显示一次亮边，复用对话框再次打开也可反馈；普通历史卡不推断状态 |
| 07 | 执行状态信号 | 可信原生任务事件或局部显式 busy；完整模式允许局部信号循环 |
| 08 | 输出状态与角色点头 | 同一次执行的首次输出触发，不按 token 重启动画 |
| 09 | 完成、失败与取消反馈 | 按任务、执行与递增 revision 去重；取消使用平静收束，历史任务不重播 |
| 10 | 工具状态、展开边缘与明确箭头过渡 | 支持已分类容器中的嵌套展开按钮及原生 activity header；按压反馈不再压掉展开反馈，代码区保持稳定 |
| 11 | 文件变更批次亮边 | 初始历史结果静态；新增稳定批次可复用同一 DOM，旧批次返回或重挂载不重播 |
| 12 | 子代理状态与结束反馈 | 只绑定明确 host／线程／执行身份；不恢复逐行持续发光 |
| 13 | 背景切换淡化 | 新图解码成功后交接有界旧图快照；过大、复合背景或无法确认时直接切换，解码失败保留旧主题 |
| 14 | 独立像素角色姿态与内置壁纸眨眼 | 角色支持专注、待确认、平静及完成姿态；壁纸眼部只匹配已校验内置素材与投影，不套用到用户图片 |
| 15 | 星点、紧凑直播装饰与微幅视差 | 完整模式首页、空间足够时启用，视差限制在水平 ±3px／垂直 ±2px；避让正文、代码、面板及控件 |
| 16 | 设置／工具页选项与折叠反馈 | 复用明确选中属性、键盘按压及嵌套展开支持；保留原生 switch 尺寸 |
| 17 | 原生主题操作忙碌反馈 | macOS 指示器／静态图标，Windows 内存生成的静态粉青沙漏，结束恢复；仅表示皮肤工具自身操作，遵守模式与状态开关 |

## 统一策略

三端共享 `system`、`off`、`subtle`、`full` 四档和五个独立效果开关。权限、变更与任务终态属于 `status`，菜单、卡片入场及按压属于 `interactions`；关闭交互反馈不会关闭任务状态提示。

减少动态效果、页面隐藏、输入法组合、滚动、路由与主题切换均有暂停或清理路径。动效不隐藏或缩放原生内容，不接管菜单定位；装饰始终不可交互，空间不足时隐藏。任务结果依赖明确事件，缺失身份或状态证据时保留静态界面。

外部 Studio、主题作者任意 keyframes、多图／视频包和新增壁纸表情素材不是上述 17 项客户端效果的交付前提。它们仍需单独的素材或格式设计；本实现不放宽主题 ZIP 与 Safe CSS 合同。
