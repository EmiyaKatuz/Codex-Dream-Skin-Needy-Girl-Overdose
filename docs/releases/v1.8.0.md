# 超天酱 v1.8.0

**中文** · [English](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.8.0/docs/releases/v1.8.0-en.md)

内置壁纸中的超天酱现在会眨眼；同时修复完整模式下旧装饰动画被统一样式关闭、只剩静止元素的问题。

## 新增功能

- **壁纸人物眨眼**：为内置 JPEG 壁纸加入与人物双眼对齐的动画层，随窗口尺寸重新定位。Windows、macOS 与 Linux 共用同一实现，Windows Acrylic 模式同步壁纸图层的透明度和位置。
- **统一控制**：人物动画在首页播放，由「完整」模式和角色开关控制；系统减少动态效果、关闭／轻量模式、页面隐藏与输入法组合期间暂停。

## 修复与改进

- **Windows 动画播放**：完整模式下，符合布局条件的原有跑马灯、轨道、reaction、心电与音乐装饰恢复播放；关闭、轻量、暂停或背景氛围关闭时继续停止。
- **布局与生命周期**：保留正文、输入区与控件避让。动画不会接管原生加载图标，热重注入或恢复官方外观时清理临时图层和监听器。
- **播放回归**：新增针对完整 Windows 系统／Acrylic 主题 payload 的浏览器回归，检查动画时间推进与实际样式变化，避免只验证元素存在。

## 升级与使用

退出 Codex、Dream Skin 托盘及主题管理器后覆盖安装，再从 `Codex Dream Skin` 启动。现有主题与动效设置保留，默认「跟随系统」仍为轻量，不会自动开启持续动画。

Windows 在托盘的「动态效果」选择「完整」并开启「角色反应」；macOS 在菜单栏的「主题 → 动态效果」选择「完整」并开启「角色动态」。Linux 使用 `motion-settings-linux.sh --set-mode full`，并保持角色开关开启。

壁纸人物动画仅适用于本版本内置的原始 JPEG，不会在自定义背景上套用人物双眼图层。窗口裁切、原生内容遮挡或布局不适合时，相关装饰可以保持隐藏；系统减少动态效果始终优先于完整模式。
