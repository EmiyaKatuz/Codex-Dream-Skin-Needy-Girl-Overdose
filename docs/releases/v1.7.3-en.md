# INTERNET ANGEL v1.7.3

[中文](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.7.3/docs/releases/v1.7.3.md) · **English**

Fixes the character, stars, and status feedback remaining static even when Full motion and system animations are enabled.

## Fixes

- When Codex recreates its main surface, motion now releases the removed surface and reconnects to the current one instead of remaining paused indefinitely. The shared runtime fix is included for Windows, macOS, and Linux.
- Binding also recovers when the main surface temporarily disappears or the interface has many tracked nodes. Truly offscreen surfaces continue to pause, and layout measurements remain deferred during input-method composition.

## Upgrading and usage

Quit Codex, the Dream Skin tray, and the theme manager before installing the update, then launch `Codex Dream Skin`. Existing themes, personal preferences, and motion settings are preserved.

Packages remain unsigned. Follow the platform installation guide for first-run steps.
