# 超天酱 v1.5.20

针对 [Issue #29](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/issues/29) 的新版 Codex 聊天区白屏症状，修复会隐藏整个消息与输入区域的旧样式，并适配 Codex 26.924–26.928 已报告的界面结构。

## 更新内容

- 顶部渐隐仅清除装饰背景，不再隐藏带 `data-app-shell-main-content-top-fade` 的内容容器。
- 新版首页输入框不再套用旧首页首个元素的固定尺寸和装饰。
- 适配外层页面、Projects、Pull Requests、Customize 和输入区渐隐背景，保留弹窗、菜单、表单和卡片底色。
- Internet Angel 扩展识别仅带 CSS Module 类的输入框和工具栏，并同步 Windows、macOS、Linux 资产与选择器合同。

## 验证范围

云端 Node 回归 198 项通过、3 项因平台条件跳过；Chromium 的 19 个合成 DOM 场景通过，包括旧 CSS 导致内容隐藏的前后对照、输入交互和多尺寸首页。平台原生回归与安装包构建由 GitHub Actions 执行。

未运行官方 Codex App 实机验收。Issue #29 未附 DOM 或 Verify 日志，本次修复处理与其症状一致的已复现缺陷，尚未确认报告者机器上的唯一根因。详细证据见 [兼容性说明](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.5.20/docs/codex-26-928-compatibility.md)。

## 更新

Windows 下载 `CodexDreamSkin-Setup-v1.5.20.exe`，macOS 下载 `CodexDreamSkin-v1.5.20.dmg`，对照同一 Release 的 `SHA256SUMS.txt` 核对摘要。安装后使用皮肤菜单中的“重新应用皮肤”。

Linux 源码运行时同步到 1.5.20，本次 Release 提供 Windows 和 macOS 安装包。
