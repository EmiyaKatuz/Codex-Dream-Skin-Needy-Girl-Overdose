# Internet Angel v1.7.2

[中文](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.7.2/docs/releases/v1.7.2.md) · **English**

Fixes v1.7.1 removing package resources while leaving retired built-in themes visible in existing tray and theme-manager libraries.

## Fixes

- A one-time upgrade moves unchanged Gothic, Arina, lossless Pixel Cafe PNG and old generic presets, including saved copies with unchanged configuration, out of the visible library. The default Internet Angel JPEG remains.
- If a recognized retired theme is active, its complete files are backed up before safely switching to the JPEG default. Windows installation, tray startup and application startup share this migration; macOS runs it on installation and menu-bar App launch, and Linux runs it during installation.
- Personal and imported themes, themes with custom CSS or edited configuration, and preferences are preserved. Names alone never trigger cleanup. Backups explicitly restored after migration are not moved away again on every launch.

## Upgrading and backups

Quit Codex, the tray and theme manager before installing over the existing version. Backups are stored in `%LOCALAPPDATA%\CodexDreamSkin\retired-themes` on Windows, `~/Library/Application Support/CodexDreamSkinStudio/retired-themes` on macOS, or `retired-themes` inside the Linux state directory. Each migration retains originals and a mapping manifest; theme files are not permanently deleted.

If a theme named “Pixel Cafe” remains, its content does not match a confirmed retired preset. To remove an unwanted entry, first select the JPEG “超天酱 · INTERNET ANGEL” from the tray, then select the old entry in theme management and move it to the Recycle Bin.

Packages remain unsigned. Real signed-in Codex sessions and the complete native installation/recovery interaction still require device testing.
