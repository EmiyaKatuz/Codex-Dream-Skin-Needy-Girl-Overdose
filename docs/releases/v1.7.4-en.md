# INTERNET ANGEL v1.7.4

[中文](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.7.4/docs/releases/v1.7.4.md) · **English**

Fixes the character, stars, and status decorations remaining invisible even while Full motion animations are running.

## Fixes

- When a right-side diff pane and left-side scroll rail occupy the window edges, decorations now search additional interior gaps. Previously, placement tried only a few edge positions and left decorations hidden when all were occupied.
- The character and stars select non-overlapping areas, check the full space required by each decoration and its parallax, and share a bounded sampling budget.
- Native text, diffs, the composer, buttons, and scroll regions remain protected. Decorations stay hidden when no complete gap is available. The fix is included in the shared Windows, macOS, and Linux runtime.

## Upgrading and usage

Quit Codex, the Dream Skin tray, and the theme manager before installing the update, then launch `Codex Dream Skin`. Existing themes and motion settings are preserved.
