# Internet Angel v1.7.1

[中文](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.7.1/docs/releases/v1.7.1.md) · **English**

The bundled theme collection now contains only the customized default JPEG edition of Internet Angel, preserving its existing visuals and motion.

## Improvements

- Windows, macOS and Linux source distributions and packages remove Gothic, the Arina reference preset and the lossless Pixel Cafe PNG edition. The old generic macOS default is also replaced with the Internet Angel JPEG.
- New Windows and macOS theme libraries contain this single bundled theme. Package inventories, theme entries and obsolete documentation assets are updated accordingly.

## Upgrading and usage

Install over the existing version. Existing active and saved themes, imported images and preferences are preserved; this cleanup does not automatically delete old themes from local libraries. To remove an old local theme, first switch to the retained JPEG edition, then delete the unused theme through theme management.

Packages continue to use the existing unsigned release process. Validation covers portable regressions, native platform CI and package checks. Real signed-in Codex sessions, native file pickers and the complete upgrade/recovery interaction still require device testing.
