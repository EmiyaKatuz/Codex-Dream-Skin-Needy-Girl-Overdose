# INTERNET ANGEL v1.9.0

[中文](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.9.0/docs/releases/v1.9.0.md) · **English**

P-chan is the new independent pixel companion, with expressions and poses that follow task state. This release completes client feedback for motion roadmap items 01–17 and fixes Acrylic Home overlap and decorations appearing inside settings panels.

## New features

- **Eight P-chan state frames**: Waiting, idle, running, streaming, needs attention, completed, failed and cancelled each have distinct eyes, mouth, front paws and tail. Completion raises the paws with a heart, failure adds drooping ears and tears, and cancellation settles calmly. All frames retain the existing 48×56 reservation.
- **Pointer and keyboard feedback**: Buttons, sidebar, settings, environment actions and tool disclosures support pointer and Enter/Space feedback while preserving native actions. Repeated keys, IME composition, disabled controls and native animations are excluded.
- **Windows theme-operation busy icon**: The tray shows a memory-only static pink/cyan hourglass while the theme tool performs its own operations, then restores the original icon. It follows the motion mode and task-status effect switch.

## Fixes and improvements

- **Independent effect switches**: Disabling interaction feedback no longer disables permission, file-change or terminal task-state cues.
- **Reused menus and results**: Persistent menus and permission dialogs receive feedback when actually opened and clear it immediately on closing. Reused file-result cards can highlight a new batch without replaying old batches or history.
- **Home cards**: Owned presets and project cards use stable identities to avoid replay, with staggered feedback limited to the first four cards. Windows Acrylic cards stay in normal flow above the composer and Send button.
- **Tool disclosures**: Nested disclosure buttons and known native activity headers are supported. Press feedback no longer suppresses expansion feedback, and code geometry remains stable.
- **Light mode and panel protection**: Fixes conflicting text/background rules on settings inputs. Character, status and ambient decorations avoid the entire settings panel, including the legacy panel structure used by Acrylic.

## Upgrading and usage

Quit Codex, the Dream Skin tray and the theme manager before installing the update, then launch `Codex Dream Skin`. Existing themes and motion settings are preserved. The default Follow system mode remains Subtle.

On Windows, enable Character reactions under Motion effects in the tray. On macOS, enable Character motion under Theme → Motion. Full mode enables continuous Home decorations when the layout permits. On Linux, use `motion-settings-linux.sh --set-mode full` and `--set-effect character on`.

P-chan appears with the built-in theme, and task feedback follows recognized state events. Decorations avoid content, pause or hide when space is insufficient, content obscures them, the page is hidden, IME composition is active or system reduced motion applies. Wallpaper blinking still requires the original bundled JPEG.
