# 超天酱 v1.6.0

新增三端统一动效设置和任务状态反馈，并修复新版 Codex 的窄窗口布局、顶栏按钮遮挡及浅色模式对比度。

## 更新内容

- 提供跟随系统、关闭、轻量、完整四档，以及交互反馈、任务状态、角色、背景氛围、主题切换五个独立开关。默认跟随系统：通常采用轻量效果，系统要求减少动态效果时关闭主题动画。
- 根据原生事件呈现执行、输出、并行审批、完成、失败、取消与工具／子代理状态；补齐聚焦、按压、菜单与项目入场反馈、独立像素角色、小范围星点视差和背景淡化。
- 页面隐藏、输入法组合、滚动和模态窗口期间暂停或避让装饰，空间不足时隐藏，保留原生控件交互。
- 首页主题卡进入正常布局，短窗口使用紧凑卡片，窄窗口的横幅和辅助面板纵向排列，避免覆盖标题、输入区及其他组件。
- 修正固定顶栏中聊天菜单、摘要和侧栏按钮的命中区域；改善浅色正文、编辑结果卡、设置输入文字与占位符、工具页面的视觉一致性。

## 设置入口

macOS：菜单栏 → 主题 → 动态效果。Windows：托盘 → 动态效果。Linux：`bash linux/scripts/motion-settings-linux.sh --set-mode subtle`；安装后使用安装目录下的同名脚本。设置无需重启 Codex。

完整行为、效果开关和支持范围见[统一动效系统](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.6.0/docs/theme-motion.md)。角色为独立装饰；本版本不包含壁纸人物差分、多图或视频主题包、任意作者动画及外部 Studio 协议。

## 验证范围

云端免登录验收覆盖 77 个截图场景，包括原版对照、深浅色、宽窄及短窗口、任务、动效、菜单和辅助页面。核对关键控件的几何位置与点击命中，未发现检查范围内主题引入的覆盖或裁切。便携 Node 回归 285 项：282 通过、0 失败、3 项因平台条件跳过；共享同步、选择器合同及三端 payload 检查通过。发布流程另外执行平台回归与安装包构建校验。

界面验收使用社区发行包中的未修改上游 **26.1002.52244** 前端，在云端 Chromium 和受控离线宿主中运行。未验证完整 Electron 原生窗口、在线模型后端、原生文件选择器或各平台 GPU 性能；终端仅显示固定测试文本。详细范围见上方动效说明。
