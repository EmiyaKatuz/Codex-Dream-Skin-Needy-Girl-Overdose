# Internet Angel v1.7.0

[中文](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.7.0/docs/releases/v1.7.0.md) · **English**

This release integrates upstream v1.5.21 compatibility and theme management updates, plus this fork's PR #33 typing and navigation optimizations. It preserves the Internet Angel visuals, shared three-platform motion system and existing theme data.

## New features

- **Background transparency**: the macOS menu bar and Windows native theme manager save transparency per theme and offer Follow theme. Personal preferences take priority over explicit author alpha; legacy themes default to 30% transparency. Text and icons remain readable, and downloaded theme packages are unchanged.
- **Saved theme management**: Windows uses a native manager. Both macOS and Windows can move an unused saved theme to the system Trash or Recycle Bin after confirmation. Switch away from an active theme first; original ZIP files and recovery backups are retained.

## Fixes and improvements

- **Typing and navigation**: reduce recursive text reads, repeated DOM scans and geometry measurements during Internet Angel classification. Coalesce refreshes, pause during IME composition, cache a limited set of stable layout conditions and reduce light-rule and editor style invalidation in dark windows. Animation and visual hierarchy remain. Official app editing and layout costs can still cause stalls; this release does not promise to eliminate all latency.
- **Current Codex surfaces**: integrate upstream 26.930 adaptations for inactive cached pages, Home, titlebars, utility pages, code blocks and expanded tables while preserving this fork's later layout, blank-screen protection and native window verification.
- **Windows startup**: respect an existing `CODEX_HOME` and bind configuration backups to their source directory. Invalid paths and restoration across different directories fail explicitly. Nonfatal Node stderr warnings no longer cause false installation or theme-operation failures; real exit codes and diagnostics remain available.
- **Theme application and packaging**: the tray confirms application through the child process's renderer verification and keeps operations mutually exclusive during the transaction. Installers and atomic patches include the full performance-cache and motion runtime dependencies.
- **macOS process identity**: read recorded start times under a fixed locale so system language does not cause session-identity mismatches.

## Upgrading and usage

Install the new package over the existing version; themes, images and configuration backups are preserved. Motion controls remain under Theme → Motion on macOS and Motion in the Windows tray. Linux receives the shared Internet Angel classifier, motion and performance runtime. This Release provides Windows and macOS installers; native transparency and theme-manager windows apply to those two platforms.

With a custom `CODEX_HOME`, the installer, tray and official Codex must receive the same directory setting. If macOS cannot identify an old session after upgrading, quit it completely and restart, rebooting if needed. Do not terminate a process based only on its recorded PID.

The packages remain unsigned. Portable tests, synthetic browser checks and CI builds do not establish validation of a real signed-in Codex session. Full Electron windows, native file pickers and the real upgrade/recovery combinations still require validation on their respective platforms.
