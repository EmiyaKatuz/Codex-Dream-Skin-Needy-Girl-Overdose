# INTERNET ANGEL v1.8.0

[中文](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.8.0/docs/releases/v1.8.0.md) · **English**

The character in the bundled wallpaper now blinks. This update also fixes shared styles disabling existing decorative animations in Full mode and leaving them as static elements.

## New features

- **Wallpaper character blinking**: Integrates the half-closed and closed pixel frames from v1.3.4, restoring the open → half-closed → closed → half-closed → open sequence. The interval is 50% shorter, from 11.4 to 5.7 seconds, while the blink gesture retains its original speed. The animation layer aligns with both eyes in the bundled JPEG and repositions when the window changes size. Windows, macOS, and Linux share the implementation; Windows Acrylic mode matches the wallpaper layer's opacity and position.
- **Unified controls**: The wallpaper animation plays on Home and follows Full mode and the character toggle. System reduced motion, Off or Subtle mode, hidden pages, and IME composition pause it.
- **Adapted legacy effects**: The large character orbit becomes a small companion halo. The music record, equalizer, heartbeat, signal waveform, and floating +1 reaction fit inside the existing collision-checked area. Their original motion cadence is retained while their layout works with the current Home and Acrylic mode, outside native text and the composer.

## Fixes and improvements

- **Windows animation playback**: Existing ticker, orbit, reaction, heartbeat, and music decorations animate again in Full mode when their layout permits. They remain stopped in Off or Subtle mode, while paused, or when ambient decoration is disabled.
- **Transparency and ultrawide displays**: The wallpaper and blinking keep working when Windows transparency effects are off or high contrast is active. Ultrawide displays retain placement budgets for status, character, and stars. Native controls that move or appear through style changes trigger a fresh collision check.
- **Layout and lifecycle**: Native text, the composer, and controls remain protected from decorative overlap. Animations do not take over native loading indicators; reinjection and restoring the official appearance clean up temporary layers and listeners.
- **Playback regressions**: Adds browser regressions using the complete Windows system and Acrylic theme payloads. They check advancing animation time and changing rendered styles, rather than only checking whether elements exist.

## Upgrading and usage

Quit Codex, the Dream Skin tray, and the theme manager before installing the update, then launch `Codex Dream Skin`. Existing themes and motion settings are preserved. The default Follow system mode remains Subtle and does not automatically enable continuous animations.

On Windows, choose Full under Motion effects in the tray and enable Character reactions. On macOS, choose Full under Theme → Motion and enable Character motion. On Linux, use `motion-settings-linux.sh --set-mode full` and keep the character toggle enabled.

Wallpaper character animation applies only to the original JPEG bundled with this version; eye layers are not applied to custom backgrounds. Decorations may stay hidden when the window crops them, native content obscures them, or the layout is unsuitable. System reduced motion always takes precedence over Full mode.
