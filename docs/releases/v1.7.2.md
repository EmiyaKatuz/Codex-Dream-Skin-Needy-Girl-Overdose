# 超天酱 v1.7.2

**中文** · [English](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.7.2/docs/releases/v1.7.2-en.md)

修复 v1.7.1 只精简安装包、升级后托盘和主题管理器仍显示旧内置主题的问题。

## 修复

- 升级时一次性将未改动的 Gothic、Arina、Pixel Cafe 无损 PNG 和旧通用预设，以及配置未改动的保存副本移出可见主题库；默认 JPEG 超天酱继续保留。
- 若正在使用识别出的旧主题，先完整备份，再安全切回 JPEG 默认主题。Windows 的安装、托盘与应用启动共用此迁移；macOS 在安装和菜单栏 App 启动时执行，Linux 在安装时执行。
- 自建、导入、增加了自定义 CSS 或修改过配置的主题与个人设置保留；同名主题不会仅凭名字被清理。迁移完成后用户主动恢复的备份不会在每次启动时再次移走。

## 升级与备份

退出 Codex、托盘和主题管理器后覆盖安装。备份位于 Windows 的 `%LOCALAPPDATA%\CodexDreamSkin\retired-themes`、macOS 的 `~/Library/Application Support/CodexDreamSkinStudio/retired-themes`，或 Linux 状态目录下的 `retired-themes`。每次迁移保留原件及对应清单，不永久删除主题文件。

若某个「Pixel Cafe」仍在列表中，说明其内容不符合已确认的旧预设。确认不需要时，先从托盘切到 JPEG 版「超天酱 · INTERNET ANGEL」，再在主题管理器中选中该条目移到回收站。

安装包保持现有未签名发布方式；真实 Codex 登录会话和完整原生安装／恢复交互仍需实机验证。
