# 超天酱 v1.7.1

**中文** · [English](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.7.1/docs/releases/v1.7.1-en.md)

精简内置主题，仅保留做过专属定制的「超天酱 · INTERNET ANGEL」默认 JPEG 版，延续原有视觉与动效。

## 改进

- Windows、macOS 与 Linux 的源码和发行包移除 Gothic、Arina 参考预设及 Pixel Cafe 无损 PNG 版；macOS 的旧通用默认主题也替换为超天酱 JPEG。
- Windows 与 macOS 的全新主题库只提供这一套内置主题；同步清理安装包、主题入口和过时的文档资源。

## 升级与使用

覆盖安装即可。已有的活动主题、已保存主题、导入图片和设置保留；此次精简不会自动删除本地主题库中的旧主题。需要清理本地旧主题时，请先切换到保留的 JPEG 版，再通过主题管理入口删除未使用的主题。

安装包继续采用现有未签名发布方式。本次通过便携回归、原生平台 CI 和安装包校验；真实 Codex 登录会话、原生文件选择器及完整升级／恢复交互仍需实机验证。
