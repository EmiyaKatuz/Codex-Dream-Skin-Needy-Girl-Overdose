# Codex Dream Skin v1.9.1

[中文](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.9.1/docs/releases/v1.9.1.md) · **English**

This release adds a Windows notification compatibility mode and improves how the launcher recognizes Codex pages during startup.

## Windows notification compatibility

On the x64 Codex Store builds `26.1027.3384.0` and `26.1103.4239.0`, you can explicitly use the regular Codex profile so official Windows activation reuses the app instance that owns the themed window. The launcher checks the Store package, Windows session, debugging port and window ownership. It preserves running Codex processes if verification fails.

## Fixes and improvements

The Windows launcher correctly handles an empty CDP page list or a list containing a single page.

## Upgrading and usage

Quit Codex from its tray menu, then run the following command in PowerShell to start an installed copy of Dream Skin. Specify this option each time you start with the regular profile.

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File "$env:LOCALAPPDATA\CodexDreamSkin\engine\scripts\start-dream-skin.ps1" -UseOfficialProfile
```

While this mode is active, local processes can access the regular Codex session through the unauthenticated loopback CDP port. Fully quitting Codex closes the port. [Security boundary](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.9.1/SECURITY.md)
