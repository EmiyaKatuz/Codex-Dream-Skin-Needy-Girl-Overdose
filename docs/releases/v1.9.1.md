# Codex Dream Skin v1.9.1

**中文** · [English](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.9.1/docs/releases/v1.9.1-en.md)

本次更新提供 Windows 通知兼容模式，并改进皮肤启动时对 Codex 页面列表的识别。

## Windows 通知兼容模式

在 x64 Store 版 Codex `26.1027.3384.0` 和 `26.1103.4239.0` 上，可以显式使用 Codex 的常用配置目录，让 Windows 官方激活请求复用皮肤窗口所属的应用实例。启动器会核对 Store 包、Windows 会话、调试端口和窗口归属。验证失败时保留正在运行的 Codex 进程。

## 修复与改进

Windows 启动器可正确处理空的 CDP 页面列表和只有一个页面的列表。

## 升级与使用

从 Codex 托盘菜单完全退出后，在 PowerShell 中使用以下命令启动已安装的 Dream Skin。每次使用常用配置启动时均需指定此选项。

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File "$env:LOCALAPPDATA\CodexDreamSkin\engine\scripts\start-dream-skin.ps1" -UseOfficialProfile
```

启用此模式期间，本机进程可通过无身份验证的回环 CDP 端口访问常用 Codex 会话。完全退出 Codex 会关闭该端口。[安全说明](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.9.1/SECURITY.md)
