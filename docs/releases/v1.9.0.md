# 超天酱 v1.9.0

**中文** · [English](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.9.0/docs/releases/v1.9.0-en.md)

阿P（P-chan）成为新的独立像素伙伴，随任务状态切换表情和姿态。本版同时补齐动效计划 01–17 的客户端反馈，修复 Acrylic 首页遮挡和设置面板装饰覆盖问题。

## 新增功能

- **阿P八状态差分**：等待、空闲、执行、输出、待确认、完成、失败和取消分别使用不同的眼神、嘴型、前爪和尾巴。完成时举爪并显示爱心，失败时垂耳流泪，取消后平静收束；所有差分保持原有 48×56 占位。
- **鼠标与键盘反馈**：按钮、侧栏、设置、环境操作及工具展开支持鼠标与 Enter／空格反馈，保留原生操作，避开重复按键、输入法、禁用控件和原生动画。
- **Windows 主题操作忙碌图标**：主题工具执行自身操作时，托盘显示内存生成的静态粉青沙漏，结束后恢复原图标；受动效模式与任务状态开关控制。

## 修复与改进

- **反馈开关**：关闭交互反馈不再连带关闭权限、文件变更或任务终态提示。
- **菜单与结果复用**：预挂载菜单和权限对话框按实际打开边界反馈，关闭时立即清理；同一文件结果卡可按新批次反馈，旧批次及历史结果不重复播放。
- **首页卡片**：自有首页卡及项目卡使用稳定身份去重，错峰反馈限制为首批四项；Windows Acrylic 卡片保持正常文档流，避免覆盖输入框和发送按钮。
- **工具展开**：支持嵌套展开按钮和已知原生 activity header，按压反馈不再压掉展开反馈，代码区域保持稳定。
- **浅色与面板避让**：修复设置输入框文字与底色的级联冲突；角色、状态和背景装饰避让整个设置面板，包括 Acrylic 使用的旧面板结构。

## 升级与使用

退出 Codex、Dream Skin 托盘及主题管理器后覆盖安装，再从 `Codex Dream Skin` 启动。现有主题与动效设置保留，默认「跟随系统」仍为轻量模式。

Windows 在托盘「动态效果」中开启「角色反应」；macOS 在「主题 → 动态效果」中开启「角色动态」。选择「完整」可显示适合首页布局的持续装饰。Linux 可使用 `motion-settings-linux.sh --set-mode full` 和 `--set-effect character on`。

阿P随内置主题显示，任务反馈依据已识别的状态事件。空间不足、内容遮挡、页面隐藏、输入法组合或系统减少动态效果时，装饰会避让、暂停或隐藏；内置壁纸眨眼仍只匹配随附原始 JPEG。
