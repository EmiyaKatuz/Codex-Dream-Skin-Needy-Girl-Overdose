# 超天酱 v1.5.19

本次同步上游 `Fei-Away/Codex-Dream-Skin@34335d2`，保留超天酱背景、Pixel Cafe 预设、Internet Angel 扩展和本仓库更新地址。

## 更新内容

- 适配新版 Codex 输入框、首页建议卡、用户消息气泡和 Markdown 宽表格，保留自定义字体及首页输入框圆角。
- 延续 Codex 26.818 / 26.820 环境面板、输入区渐隐和文件变更摘要的兼容修复。
- 排除 Pet 透明窗口，清理旧注入，避免主题背景覆盖宠物窗口。
- Windows 默认创建并复用受管 CDP profile，解决新版 Chromium 忽略默认数据目录远程调试参数的问题。首次使用该 profile 需要登录 Codex，之后复用该目录。
- Windows 渲染验证会检查横向溢出，避免把越出窗口的页面判为成功。
- macOS 重新应用皮肤时尊重退出取消；更新检查遇到 GitHub API 限流时，从本仓库最新 Release 的跳转地址获取版本。
- macOS 更新检查优先使用 App 包内脚本，避免已部署引擎的旧版本号触发重复更新提示。
- Windows 安装包构建为运行时下载设置超时，单独记录 PowerShell 5.1 与 7 回归步骤，避免构建长时间挂起。
- CDP 端点长时间不可用时，watcher 逐步延长重试和错误日志间隔。

## 安装

Windows 下载 `CodexDreamSkin-Setup-v1.5.19.exe`，macOS 下载 `CodexDreamSkin-v1.5.19.dmg`。安装前对照同一 Release 的 `SHA256SUMS.txt` 核对文件摘要。

Linux 源码运行时同步到 1.5.19，本次 Release 提供 Windows 和 macOS 安装包。
