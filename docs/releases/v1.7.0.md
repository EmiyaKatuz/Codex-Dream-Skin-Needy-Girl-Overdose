# 超天酱 v1.7.0

**中文** · [English](https://github.com/EmiyaKatuz/Codex-Dream-Skin-Needy-Girl-Overdose/blob/v1.7.0/docs/releases/v1.7.0-en.md)

整合上游 v1.5.21 的兼容性与主题管理更新，以及本项目 PR #33 的输入和导航性能优化，保留超天酱视觉、三端统一动效及已有主题数据。

## 新增功能

- **背景透明度**：macOS 菜单栏与 Windows 原生主题管理器支持按主题保存透明度，并可选择“跟随主题”。个人设置优先于作者明确提供的 alpha；历史主题默认采用 30% 透明度。文字和图标保持可读，不改写下载的主题包。
- **已保存主题管理**：Windows 使用原生管理窗口；macOS 和 Windows 可在确认后将未使用的已保存主题移到系统废纸篓或回收站。使用中的主题需先切换，原始 ZIP 和恢复备份保留。

## 修复与改进

- **输入与导航**：减少超天酱组件分类时的递归文本读取、重复 DOM 扫描和几何测量；合并刷新并在输入法组合期间暂停，缓存有限的稳定布局条件，减少深色界面中浅色规则和编辑区的样式失效。保留动画与视觉层次；仍可能受到官方应用自身编辑和布局耗时影响，不承诺消除所有卡顿。
- **新版 Codex 界面**：整合上游 26.930 对隐藏缓存页面、首页、顶栏、工具页、代码块和展开表格的适配，并保留本项目后续加入的布局、白屏防护和原生窗口校验。
- **Windows 启动**：遵循已有的 `CODEX_HOME`，配置备份绑定来源目录；无效路径或跨目录恢复会明确停止。Node 的非致命 stderr 警告不再被误判为安装或主题操作失败，真实退出码和诊断仍保留。
- **主题应用与打包**：托盘根据子进程的渲染验证确认应用结果，并在事务处理中保持操作互斥；安装包和原子补丁包含性能缓存与动效所需的完整运行时依赖。
- **macOS 进程识别**：使用固定语言环境读取记录的启动时间，避免系统语言造成会话身份误判。

## 升级与使用

使用新版安装包覆盖安装，原有主题、图片及配置备份保留。动效入口仍在 macOS 的“主题 → 动态效果”和 Windows 托盘的“动态效果”。Linux 同步共享超天酱组件、动效与性能运行时；本次 Release 提供 Windows 和 macOS 安装包，原生透明度与主题管理窗口仅适用于这两个平台。

自定义 `CODEX_HOME` 时，安装器、托盘与官方 Codex 必须获得同一目录设置。若升级后 macOS 无法确认旧会话，请完整退出后重新启动，必要时重启系统，不要仅根据旧 PID 强制结束进程。

当前安装包未签名。便携测试、合成浏览器检查与 CI 构建不等于真实 Codex 登录会话验收；完整 Electron 窗口、原生文件选择器及升级／恢复的实机组合仍需对应平台验证。
